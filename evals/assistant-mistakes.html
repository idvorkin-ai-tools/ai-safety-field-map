Testing assistants for everyday mistakes

Published test suites · 11 failure types · checked November 2026
StartSix suites that cover most of it ↓

Dangerous-capability evals ask what a model could do if misused. These suites ask something more mundane: does a chat or voice assistant invent facts, cave when you push, follow instructions hidden in a web page, or refuse a harmless question? Each section below is one kind of mistake and the public datasets built to provoke it.

Sizes are row counts from the published data unless marked (README) or (paper). "Inspect" means an inspect_evals task exists; "promptfoo" means a red-team plugin; "custom" means you write the runner. A suite that fits several mistakes gets one full row and a short pointer row elsewhere.

A six-suite starter set

One pick per cluster of mistakes, chosen for harness support and low cost: about one model call and one judge call per item unless noted.

  • SimpleQA Verified (1,000, Inspect): hallucination, with abstention visible in the “not attempted” grade.
  • FreshQA (500 test items): stale facts and false premises. No harness task, so export the CSV and grade with a rubric. Re-check the fast-changing answers first.
  • SycophancyEval are-you-sure (4,887; subsample about 500, Inspect): caving. Add MASK if lying under a system prompt matters to you.
  • CyberSecEval 2 prompt injection (251, Inspect or promptfoo): one yes/no judge call per item.
  • MultiChallenge (266): multi-turn drift. Needs a small runner that replays each conversation.
  • StrongREJECT + XSTest (313 + 450, Inspect): jailbreaks and over-refusal as a pair, so you see both sides of the refusal trade-off. Layer promptfoo's adaptive attacks on top when budget allows.

For a separate abstention number, CoCoNot (Inspect) is cheaper and more permissive than AbstentionBench. For voice, run the first, third and last picks through text-to-speech, or use VoiceBench if your endpoint takes audio.

Harnesses

  • Inspect Evals (UK AISI, MIT): ready tasks for about a third of the suites above, from truthfulqa to agentdojo. Points at any OpenAI-compatible endpoint (providers).
  • promptfoo (MIT): generated red-team plugins, a few dataset plugins, and attack strategies including multi-turn and audio. Can load any HF dataset as tests.
  • garak (NVIDIA, Apache-2.0): a scanner of probes for jailbreaks, injection, encodings, false assertions and hallucination snowballing.

Caveats

  • FreshQA is itself going stale. The newest answer sheet is dated April 21 2026; a promised May 2026 refresh never appeared, so by late November its fast-changing answers are about seven months old. Grade that slice against today's facts, not the sheet.
  • Licenses disagree with themselves. SycophancyEval has no license on GitHub but says MIT on Hugging Face. CoCoNot's card names both AI2 ImpACT-LR and ODC-BY. CyberSecEval's benchmark folder is MIT while the repo root carries the Llama 3.2 license. AbstentionBench and HalluLens are non-commercial. Check before shipping results in a product.
  • Access is not always what it says. MASK downloads ungated from Hugging Face, yet the Inspect task warns it needs a token. WildJailbreak is gated and its size could not be confirmed.
  • The judge is part of the result. Almost every suite scores with an LLM grader: budget one grader call per item and pin the grader model, or runs will not compare. Inspect's FORTRESS page links an audit warning about fragile judges.
  • Check the defaults. promptfoo generates and grades red-team tests through its remote service unless you turn that off; OpenAI's simple-evals has been frozen since July 2025.
